# Acceptance criteria

Acceptance criteria for the 51 Phase 1 functional requirements, one file per group. Each criterion is one observable behaviour in Given / When / Then form and names how it is tested. A unit is done when every criterion for its requirements is implemented and covered by its test, or is recorded as a departure in the pull request.

Alongside the criteria each requirement lists its data and validation rules, state transitions, role permissions, the database and application objects involved, and open owner points with the default assumed. Names prefixed `proposed:` are not yet in `docs/ARCHITECTURE.md`. Open points marked "to be confirmed by CHARA" use the default stated here and in `docs/OPEN_QUESTIONS.md`.
